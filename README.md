# Atlas Engineering - Enterprise Data Platform



## Overview



This repository documents the design and implementation of a complete enterprise data platform, built from scratch as a long-term engineering portfolio.



The project combines database architecture, data engineering, cloud technologies and software engineering practices, emphasizing technical documentation, reproducibility and maintainability.



## Objectives



- Learn software architecture and Git

- Learn data engineering

- Improve technical documentation

- Master Git

- SQL Server

- PostgreSQL

- Docker

- REST APIs

- Cloud Platforms

- Build a production-like enterprise platform from scratch
