# Development Environment

## Purpose

This document describes the local development environment and the primary tools used to build, manage, validate, and document the Atlas Engineering Enterprise Data Platform.

Its purpose is to provide a clear reference for the development workstation and the software dependencies required to reproduce the project environment.

## Operating System

The local development environment runs on:

- Windows 11 Pro

The operating system provides the workstation platform for the development, administration, validation, and documentation activities performed within Atlas Engineering.

## Installed Tools

The local development environment uses the following primary tools:

### Git

Used for distributed source control and local repository management.

### GitHub Desktop

Used as the graphical interface for Git operations and synchronization with the remote repository.

### Visual Studio Code

Used for repository navigation, documentation editing, script development, and general project file management.

### SQL Server 2025 Developer Edition

Used as the local relational database platform for AtlasCommerce development, deployment, and validation.

The Developer edition provides the SQL Server feature set required to develop and validate the database platform in the local non-production environment.

### SQL Server Management Studio

Used for SQL Server administration, T-SQL development, deployment execution, database inspection, and validation.

## Remote Repository

GitHub is used as the remote repository hosting platform for Atlas Engineering.

The local Git repository is synchronized with the remote repository through GitHub Desktop, providing version history, remote backup, and controlled synchronization of versioned project artifacts.
