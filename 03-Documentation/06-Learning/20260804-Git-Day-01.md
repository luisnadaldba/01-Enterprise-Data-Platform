\# Git - Day 01



Date: 2026-08-04



\---



\## Today I learned



Today I learned that Git is much more than a tool to upload code.



I understood the difference between global configuration and repository configuration, why the .git directory defines the repository root, and why choosing the correct repository location is important from the beginning.



I also learned the purpose of the most fundamental Git commands:



\- git config

\- cd

\- pwd

\- git init

\- git status



Finally, I learned the importance of documenting architectural decisions before writing source code.



\---



\## Biggest challenge



The biggest challenge was understanding where the Git repository should actually be initialized.



At first, I initialized it one level above the intended project folder. Although this could be corrected easily because there were no commits yet, it helped me understand how Git identifies the repository root.



Another challenge was resisting the temptation to start coding before defining the project structure and documentation.
